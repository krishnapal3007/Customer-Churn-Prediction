# 📊 Customer Churn Prediction using Machine Learning

## 📌 Overview
This project predicts whether a customer is likely to leave a company (Churn) or continue using its services. The model is built using Logistic Regression and trained on the Customer Churn Modelling dataset.

---

## 🚀 Features

- Data Preprocessing
- Missing Value Check
- Label Encoding
- Feature Scaling
- Exploratory Data Analysis
- Correlation Matrix
- Logistic Regression Model
- Random Forest Comparison
- Model Evaluation
- Confusion Matrix
- Feature Importance
- Customer Churn Prediction
- Model Saving using Joblib

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

---

## 📂 Dataset

Customer Churn Modelling Dataset

---

## 📈 Results

### Logistic Regression Accuracy

**81.55%**
